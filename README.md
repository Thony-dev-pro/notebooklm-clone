# notebooklm-clone

## Installation des dépendances

```bash
pip install langchain langchain-community chromadb sentence-transformers streamlit pymupdf
```

## Prérequis

Ollama doit tourner en arrière-plan. Installe-le sur [ollama.com](https://ollama.com) puis lance le modèle Mistral :

```bash
ollama run mistral
```
